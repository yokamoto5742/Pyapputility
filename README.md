# pyapp_update

## 1. 概要
このプログラムは、アプリケーションの更新を自動化するためのGUIツールです。主な機能は以下の通りです：

- 設定ファイル（config.ini）からアプリケーションの更新情報を読み込む
- 指定されたディレクトリのファイルを削除
- 新しいファイルを指定された場所にコピー
- 操作のログを記録
- ユーザーフレンドリーなGUIインターフェース

## 2. 主要なクラスと役割

### 2.1 AppConfig（データクラス）
```python
@dataclass
class AppConfig:
    name: str
    delete_dir: str
    copy_src_dir: str
    copy_dest_dir: str
```
- アプリケーションの設定情報を保持する単純なデータ構造
- 各アプリケーションの名前、削除するディレクトリ、コピー元とコピー先のディレクトリを管理

### 2.2 ConfigManager
設定ファイルの読み込みと管理を担当するクラス
- config.iniファイルを読み込む
- ログの保持期間の設定を管理（デフォルト7日間）
- 各アプリケーションの設定を読み込んでAppConfigオブジェクトとして保持

### 2.3 UpdateManager
実際のファイル操作を行うクラス
- `delete_files()`: 指定されたディレクトリ内のファイルとフォルダを再帰的に削除
- `copy_files()`: ソースディレクトリから対象ディレクトリにファイルをコピー
- `update_app()`: 削除とコピーの処理を順番に実行

### 2.4 Application
GUIアプリケーションのメインクラス（tkinterベース）
- ドロップダウンメニューでアプリケーションを選択
- 更新ボタンで処理を開始
- プログレスバーで処理状況を表示
- 処理結果をステータスラベルに表示

## 3. ログ機能の実装

### 3.1 ExcludeInternalFilter
- 内部処理に関するログを除外するためのフィルタークラス
- メッセージに"_internal"が含まれるログを除外

### 3.2 setup_logging()
- ログファイルの設定を行う関数
- 以下の特徴を持つ：
  - 日単位でログファイルをローテーション
  - コンソールとファイルの両方にログを出力
  - 設定された期間を過ぎたログファイルを自動削除

## 4. エラー処理
プログラム全体で以下のエラーに対する適切な処理が実装されています：

- ファイルの権限エラー（PermissionError）
- ファイルが見つからないエラー（FileNotFoundError）
- ファイル操作の一般的なエラー（OSError）
- 設定関連のエラー（KeyError）

## 5. スレッド処理
- ファイル操作を別スレッドで実行し、GUI操作をブロックしない
- `threading.Thread(target=self.run_update, daemon=True)`を使用
- メインスレッドとの通信には`after()`メソッドを使用

## 6. 使用方法

1. config.iniファイルに更新したいアプリケーションの情報を設定
2. プログラムを起行すると、GUIウィンドウが表示される
3. ドロップダウンメニューから更新したいアプリケーションを選択
4. 「更新開始」ボタンをクリックして処理を開始
5. 処理の進行状況がプログレスバーとステータスメッセージで表示
6. 処理完了後、結果が表示される

## 7. 設定ファイル（config.ini）の形式
```ini
[Logging]
log_retention_days=7

[App:アプリ名]
DeleteDir=削除するディレクトリパス
CopySrcDir=コピー元ディレクトリパス
CopyDestDir=コピー先ディレクトリパス
```

## 8. 特徴的な実装ポイント

1. **型ヒント**の活用
   - Pythonの型ヒントを使用してコードの可読性と保守性を向上
   - `Optional`, `Dict`, `NoReturn`などの型を適切に使用

2. **データクラス**の活用
   - `@dataclass`デコレータを使用して設定情報を簡潔に管理
   - クラス定義の簡素化とコード量の削減を実現

3. **パスの取り扱い**
   - `pathlib.Path`を使用して、クロスプラットフォームで動作するパス処理を実装
   - 従来の`os.path`に比べて、より現代的で安全なパス操作を実現

4. **ログローテーション**
   - `TimedRotatingFileHandler`を使用して、ログファイルの自動管理を実現
   - 日付ベースでログファイルを分割し、古いログを自動削除

## 9. セキュリティ考慮事項

1. ファイル操作時の権限チェック
2. エラー発生時の適切なログ記録
3. GUI操作のバリデーション
4. 設定ファイルの文字エンコーディング指定（UTF-8）
